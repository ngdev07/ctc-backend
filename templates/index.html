About the API

Cette API fournit les services backend d'une plateforme permettant aux étudiants de trouver des professeurs particuliers, de consulter leurs matières et de demander des réservations.

3 Rôles

Admin, Teacher, Student

PostgreSQL

Base de données relationnelle

JWT Auth

TEACHER

Gestion du profil, des matières et des demandes de réservation.

STUDENT

Recherche de professeurs et création de réservations.
